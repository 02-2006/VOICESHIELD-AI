# VoiceShield AI — AI-Powered Real-Time Voice Clone & Anti-Spoofing Detection Engine
**Smart India Hackathon (SIH 2026) Official Submission**

VoiceShield AI is an enterprise-grade cybersecurity audio biometric anti-spoofing system designed to detect and neutralize AI voice cloning attacks, synthetic speech (TTS/VC), vocoder artifacts, and replay impersonation attempts in real time.

## 2. Core Deep Learning Models

### A. RawNet2 (SincNet Raw Audio Front-End)
- Operates directly on time-domain 16kHz raw waveforms without lossy time-frequency conversions.
- 128 Sinc-convolutional filters with learnable Mel-scale bandpass parameters.
- Captures subtle phase discontinuities, vocal fold glottal pulse timing, and synthetic vocoder boundary errors.

### B. AASIST (Audio Anti-Spoofing with Integrated Spectro-Temporal Graph Attention)
- Integrates heterogeneous Graph Neural Networks (GNNs) across both temporal and spectral sub-graphs.
- Excels at catching cross-band correlation flaws generated by diffusion models (RVC, XTTS, ElevenLabs, VITS, HiFi-GAN).

## 3. Installation & Setup

### Prerequisites
- Python 3.11+
- FFmpeg installed (`apt install ffmpeg` or `brew install ffmpeg`)
- NVIDIA GPU with CUDA 11.8+ (CPU fallback supported automatically)

### Step 1: Clone and Create Virtual Environment
```bash
git clone https://github.com/your-org/voiceshield-ai.git
cd voiceshield-ai/backend
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### Step 2: Install PyTorch & Dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Step 3: Run FastAPI Server
```bash
python main.py
# or
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## 4. API Endpoints

### 1. Upload Detection: `POST /predict`
- **Request**: Multipart form-data with `file` (`.wav`, `.mp3`, `.m4a`, `.ogg`)
- **Response**:
```json
{
  "prediction": "FAKE",
  "confidence": 96.5,
  "threat_score": 91.2,
  "risk_level": "HIGH",
  "models": {
    "rawnet2": {
      "spoof": 0.91,
      "genuine": 0.09,
      "inference_time_ms": 42.1
    },
    "aasist": {
      "spoof": 0.88,
      "genuine": 0.12,
      "inference_time_ms": 38.4
    }
  },
  "inference_time": 0.081
}
```

### 2. Live WebSocket Stream: `WS /stream`
- **Request**: Binary 16-bit 16kHz PCM chunks (200ms - 500ms)
- **Response**: Real-time JSON threat updates every chunk.

### 3. Voice CAPTCHA: `GET /captcha/challenge` & `POST /captcha/verify`
- Dynamic anti-spoof sentence generation and verification for borderline uncertainty scores.

## 6. SIH 2026 Demo Workflow

1. **Microphone Test**: Record authentic human voice → System detects natural pitch micro-tremors and outputs **REAL VOICE (LOW THREAT)**.
2. **AI Clone Attack**: Load ElevenLabs / XTTS sample → Detects vocoder harmonic cutoff & phase alignment → Outputs **FAKE VOICE DETECTED (HIGH THREAT - 96% CONFIDENCE)**.
3. **Voice CAPTCHA Challenge**: For noisy or borderline audio, system triggers randomized phrase challenge to verify dynamic live vocal tract articulation.
4. **Explainable AI**: View interactive FFT Spectrogram, SincNet filterbank response, and acoustic artifact radar breakdown.
